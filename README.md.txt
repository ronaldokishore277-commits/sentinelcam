# SentinelCam

An intelligent mobile vision system that combines low-level camera control with real-time computer vision and on-device AI.

## Features
- Real-time object detection (people, objects)
- low-light detection and warnings
- On-device AI (privacy-focused, no cloud)
- Works in browser (no installation)

## How to Use
1. Allow camera permission when prompted
2. Point camera at scene
3. Watch as AI detects people and objects
4. Receive warnings if lighting is too dark

## Tech Stack
- HTML5 / CSS3 / JavaScript
- TensorFlow.js + COCO-SSD model
- MediaDevices API
- Canvas API
